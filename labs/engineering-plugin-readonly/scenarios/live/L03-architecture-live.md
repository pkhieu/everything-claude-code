# L03: architecture review from Confluence (HITL)

Skill: `engineering:architecture`
Systems: Confluence

## Prompt

```
/engineering:architecture
Read the Confluence page "<design or ADR page title>" in space <SPACE>.
Evaluate it as an ADR reviewer: missing decision drivers, unconsidered options, risks,
and questions for the authors. Output as a review, do not edit the page.
```

## Checklist

- [ ] Review grounded in the page content (quotes/sections referenced).
- [ ] Questions are specific and useful.
- [ ] Only read calls.
